# CollabHub Product Hunt launch film

## Style

Thirty-second, 1920x1080, silent-first developer product film. Use canvas `#edf1ed`, ink `#17231c`, primary green `#237a53`, signal yellow `#f0c766`, surface `#f8faf8`, and rules `#b9c9be`. Display voice is Archivo 900; technical voice is IBM Plex Mono 400/600. The mood is precise, open-source, and quietly confident.

## Rhythm

`HOOK — PROOF — BREATHE — CTA`

The opening lands the low-intrusion promise quickly, the real two-client product proof gets the longest hold, integration becomes a compact explanatory breath, and the final open-source CTA resolves without adding new energy.

## Global rules

- Each scene uses a light textured canvas with two to four structural background elements.
- Every scene has a foreground technical label, a midground message, and a second focal point.
- All content is understandable without audio.
- Use deterministic GSAP timelines only; no random or wall-clock behavior.
- Use a solid green cover wipe between scenes so no outgoing scene needs an exit animation.
- Use real product footage and exact project claims only.

## Scene 1 — Keep your app (0–5 seconds)

**Concept.** The existing React application stays intact while a small collaboration layer locks into place beside it. The viewer should understand the product category and differentiation within two seconds.

**Mood.** Editorial technical announcement: restrained, direct, and engineered rather than futuristic.

**Depth.** BG: oversized `COLLAB` ghost type drifts horizontally; a green radial field breathes; two registration rules draw across the canvas. MG: headline “Multiplayer, without rewriting your React app.” and a three-part architecture strip: Your React app → SDK → CollabHub service. FG: `OPEN SOURCE · v0.1.3` label and a small live-status dot.

**Choreography.** Technical label TYPES ON. Headline LOCKS IN from the left with a short blur clear. Architecture cards ASSEMBLE from three directions. Connector rule DRAWS. Live dot PULSES twice. Background ghost type DRIFTS.

**Transition.** Full-frame primary-green cover WIPES from right to left over 0.45 seconds.

## Scene 2 — Real two-client proof (5–19 seconds)

**Concept.** The product earns trust by showing the actual React Flow example running as two clients. The frame should feel like an instrument panel around real footage, not a fake mockup.

**Mood.** Calm product proof with visible diagnostics.

**Depth.** BG: faint coordinate grid, version ticks and a large `02 / LIVE PROOF` index. MG: real two-client smoke footage inside a thick surface frame. FG: Alice/Bob labels, “one graph · two browsers” status ribbon, three proof chips for incremental operations, offline recovery and linked deletion.

**Choreography.** Frame EXPANDS from 94% scale. Footage REVEALS behind a left-to-right clip. Labels SNAP to opposite corners. Proof chips CASCADE with distinct timings. A green scan rule STEPS across the bottom. Background index DRIFTS upward.

**Transition.** Focus cover: a surface panel EXPANDS from the center, then the next scene is revealed beneath it over 0.55 seconds.

## Scene 3 — Two things to add (19–26 seconds)

**Concept.** Reduce the integration story to two concrete additions: one client boundary and one deployable service. Existing components, data model, and REST remain visibly untouched.

**Mood.** Clear engineering diagram, approachable to an ordinary React developer.

**Depth.** BG: oversized braces, soft green field, technical tick marks. MG: left-side code card with `createCollabRuntime`, right-side Docker command card. FG: three keep-chips — Components, Data model, REST fallback — plus the label `YOUR APP STAYS YOUR APP`.

**Choreography.** Label TYPES ON. Keep-chips STAMP in. Code lines REVEAL top to bottom. Docker command SLIDES from the right. A connecting line DRAWS between SDK and service. Braces FLOAT slowly.

**Transition.** Signal-yellow strip WIPES upward for 0.35 seconds, followed by the final canvas.

## Scene 4 — Open source CTA (26–30 seconds)

**Concept.** Resolve on the name, open-source status and a single next action. No new technical information appears.

**Mood.** Confident, warm closure.

**Depth.** BG: one green radial field, oversized C mark, two quiet rules. MG: CollabHub wordmark and “Add multiplayer to the React app you already have.” FG: GitHub URL, Apache-2.0 badge, and `TRY THE LIVE DEMO` signal label.

**Choreography.** Mark ASSEMBLES. Wordmark LOCKS IN. Subtitle FLOATS upward. URL TYPES ON. Signal label STAMPS in. The whole final group may fade gently only in the last 0.35 seconds.

## Recurring motifs

- Horizontal rules represent versioned operations crossing clients.
- Registration marks and monospace labels communicate observability.
- Green is the collaboration path; yellow is reserved for action/status.

## Negative prompt

No dark cyberpunk canvas, no neon, no generic stock imagery, no abstract people, no fake testimonials, no pricing, no CRDT claim, no character-level rich-text claim, no glass cards, no gradient text, and no jump cuts.
