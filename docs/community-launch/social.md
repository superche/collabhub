## LinkedIn

```text
Today I am releasing CollabHub 1.0, an open-source way to add multiplayer to an existing React application.

The project starts from a practical constraint: many applications already have components, a store, business commands, authentication, REST endpoints, and production data. Adding collaboration should not require replacing all of them.

CollabHub adds one application-owned model file, a React client boundary, and a self-hosted service. The repository includes TODO List, BlockNote, React Flow, and Yjs-hybrid examples, plus Docker and persistent PostgreSQL + Redis deployment paths.

The v1.0 scope is structured application data. It does not claim to replace a character-level text CRDT; Yjs remains the recommended owner for fields that need that behavior.

I would value feedback from developers who have an existing React product: where does the integration still feel harder than it should?

Live demo: https://collabhub-demo.onrender.com/demo.html
GitHub: https://github.com/superche/collabhub
```
