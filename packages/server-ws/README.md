# @collabhub/server-ws

Standalone WebSocket transport for `@collabhub/server-core`. It owns connection binding, room leases, recovery, presence, backpressure, TTL/LRU cleanup, and graceful shutdown while the application supplies its Domain Pack and storage.

See the [React quick start](https://github.com/superche/collabhub/blob/main/docs/getting-started.md).
